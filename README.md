# bigo-check

Плагин для VS Code, который оценивает асимптотическую сложность программы на C++
по вложенности циклов.

## Возможности
- Команда «Big-O: оценить сложность файла» в палитре (Cmd/Ctrl+Shift+P)
- Определяет максимальную вложенность циклов `for` и `while`
- Выводит `O(1)`, `O(n)`, `O(n^2)` или `O(n^3)`


## Запуск
1. Откройте папку проекта в VS Code
2. Нажмите F5, откроется окно Extension Development Host
3. Откройте C++ файл (например, `example.cpp`)
4. Вызовите команду через Cmd/Ctrl+Shift+P

## Ограничения
Не учитываются циклы без `{}`, рекурсия, логарифмические циклы и вызовы функций.
