# ТЗ: плагин bigo-check
- **Автор:** Vasilev Elizar, группа — M3116
- **IDE:**  VS Code
- **Язык реализации:**  JavaScript (Node.js)

## 1. Назначение
Плагин, который по тексту открытого файла на C++ приблизительно оценивает асимптотическую точность.

## 2. Функциональные требования
1. Плагин добавляет в палитру команд VS Code (Ctrl/Cmd+Shift+P) команду **«Big-O: оценить сложность файла»** (идентификатор `bigo.check`).
3. Из текста удаляются однострочные комментарии `//`, чтобы они не влияли на результат.
4. Плагин находит циклы `for` и `while` и определяет **максимальную глубину их вложенности**.
5. Глубина переводится в оценку сложности:

   | Глубина вложенности | Результат |
   |---|---|
   | 0 | `O(1)` |
   | 1 | `O(n)` |
   | 2 | `O(n^2)` |
   | 3 | `O(n^3)` |

6. Результат показывается пользователю во всплывающем сообщении VS Code.
7. Если файл пустой, выводится сообщение «File empty».
8. Если нет открытого редактора, команда ничего не делает и не вызывает ошибку.

## 3. Алгоритм
- Текст файла делится на строки.
- Ведётся счётчик фигурных скобок `{` `}`.
- level хранит уровни скобок, на которых открыты текущие циклы; его длина — текущая вложенность.
- При закрывающей скобке из level удаляются циклы, тело которых закончилось.
- Результатом является максимальная длина за проход.

## 4. Ограничения
- Оценка: учитывается только вложенность циклов.
- Циклы без фигурных скобок, рекурсия, логарифмические циклы (`i *= 2`) и вызовы библиотечных функций не учитываются.
- Результат относится ко всему файлу, а не к отдельным функциям.
